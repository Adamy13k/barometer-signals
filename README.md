# Barometer Signals — public record

Calibrated probabilities for Polymarket daily-temperature weather markets,
from a 122-member forecast ensemble, paper-traded under live conditions.

- **[Track record](https://adamy13k.github.io/barometer-signals/)** — regenerated daily from the graded trade log
- **[signals/](signals/)** — the daily digest archive; commit history = timestamp proof

Standardised model output for information and research. Not investment advice.
